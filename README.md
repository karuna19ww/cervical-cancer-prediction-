# Cervical Cancer Risk Prediction System

## Overview

The Cervical Cancer Risk Prediction System is a web-based application designed to provide a model-based estimation of cervical cancer risk using selected demographic, reproductive, contraceptive, smoking, and sexually transmitted disease (STD) related factors.

The system provides a simple interface for entering relevant information and presents an estimated risk probability based on the implemented prediction model.

This project is developed primarily for educational and research purposes.

## Objectives

* Develop a user-friendly web interface for collecting relevant risk-factor information.
* Process user-provided data in a structured format.
* Apply a machine-learning-based prediction approach.
* Present the estimated risk probability in an understandable format.
* Deploy the application as a web application using GitHub Pages.

 
## Technologies Used

* HTML5
* CSS3
* JavaScript
* Machine Learning
* GitHub Pages

 

 ## Disclaimer

This application is developed for educational and research purposes only.

The results generated by this system are model-based estimates and should not be considered a medical diagnosis. The application is not intended to replace professional medical evaluation, diagnosis, or treatment.
